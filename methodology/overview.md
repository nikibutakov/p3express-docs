# P3.express в двух словах

> По материалам открытого руководства [P3.express (OMIMO)](https://omimo.org/ru/modules/p3.express/manual/v2/) — CC BY 4.0.

P3.express — минималистичная, практичная методология управления проектами:
лёгкая в освоении, использовании и обучении. Она создана как «Excel среди
систем управления проектами»: фундаментальные стандарты (PRINCE2, PMBOK)
мощны, но для обычных проектов избыточно сложны.

## Процесс: 33 шага, 7 этапов

```
ЗАПУСК                МЕСЯЧНЫЙ ЦИКЛ (повторяется 2–4 недели)          ЗАКРЫТИЕ   ПОСЛЕ
A01–A10   ─────►  B01–B05  ──►  C01–C04  ──►  D01–D02  ──►  E01–E03  ──►  F01–F06    G01–G03
назначение         планирование   еженедельно   ежедневно    закрытие      передача,   выгоды,
ролей,             цикла          прогресс,     реестр,      цикла:        архив,      идеи
описание,          и ревью        встречи       приёмка      уроки         финал
риски, Go/No-go
```

### Этап A — Запуск проекта (однократно)

| Шаг | Название | Суть |
|-----|----------|------|
| A01 | Назначить спонсора | Старший менеджер, отвечает за результат, финансирование, ресурсы |
| A02 | Назначить менеджера проекта | Ведёт все шаги методологии |
| A03 | Назначить ключевых членов команды | Кто нужен для запуска |
| A04 | Описать проект | → **Резюме проекта** |
| A05 | Определить ожидаемые результаты | → **Карта результатов** |
| A06 | Определить риски и меры реагирования | → **Реестр последующих действий** |
| A07 | Провести ревью запуска | Внешний взгляд: другой РП/эксперт проверяет пакет запуска |
| A08 | Решить «Go/No-go» | Спонсор принимает решение о старте |
| A09 | Провести стартовую встречу | Собрать всю команду, проговорить цель и план |
| A10 | Направить фокусированную коммуникацию | Короткое сообщение заинтересованным, кто не был на встрече |

### Месячный цикл (B–E, повторяется)

| Шаг | Название | Ритм |
|-----|----------|------|
| B01 | Обновить и детализировать планы | раз в цикл |
| B02 | Провести ежемесячное ревью → **Реестр «Здоровье проекта»** | раз в цикл |
| B03 | Решить «Go/No-Go» | раз в цикл |
| B04 | Провести стартовую встречу цикла | раз в цикл |
| B05 | Направить фокусированную коммуникацию | раз в цикл |
| C01 | Оценить и зафиксировать прогресс | еженедельно |
| C02 | Реагировать на отклонения | еженедельно |
| C03 | Провести еженедельную встречу | еженедельно |
| C04 | Направить фокусированную коммуникацию | еженедельно |
| D01 | Управлять рисками, проблемами, запросами на изменения | ежедневно |

### Этап F — Закрытие проекта

F01 Передать продукт · F02 Оценить удовлетворённость · F03 Ревью закрытия ·
F04 Заархивировать документацию · F05 Отметить окончание · F06 Коммуникация

### Этап G — После проекта

G01 Оценить полученные выгоды · G02 Сгенерировать новые идеи · G03 Коммуникация.
Запускается через несколько месяцев после закрытия — проверить, достигнуты ли выгоды.

## Роли

- **Менеджер проекта** — возглавляет команду управления проектом, отвечает за реализацию шагов;
- **Команда управления проектом** — один или более участников (зависит от размера);
- **Спонсор** — старший менеджер: результат, финансирование, ресурсы, решения Go/No-go;
- **Тимлид** — возглавляет каждую внутреннюю команду разработки;
- **Менеджер проекта со стороны подрядчика** — возглавляет внешнюю команду;
- **Внешний менеджер проекта со стороны заказчика** — при внешнем заказчике;
- **Функциональный менеджер** — руководитель тимлида, если есть в организации.

Методология применяется **со своей точки зрения** («рабурс»): каждый участник
ведёт свой комплект документов для своего угла зрения на проект.

## Принципы

Работа проекта должна соответствовать **NUPP** — «Почти универсальным проектным
принципам» (NUP1: ответственность, NUP2: экономия ресурсов, NUP3: общий язык,
NUP4: слабое звено цепи, NUP5: ничего без ясной цели, NUP6: воспроизводимые
элементы) — открытому своду принципов OMIMO.

## Адаптация

P3.express можно адаптировать под своё окружение, но: не ломайте внутреннюю
согласованность, сохраняйте простоту, начинайте с оригинала и корректируйте
постепенно, проверяя каждое изменение.
