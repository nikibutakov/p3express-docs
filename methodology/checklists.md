# Чек-листы P3.express

Практические списки для запуска и ритма проекта. Отмечайте по ходу.

## Запуск проекта (этап A)

- [ ] A01. Назначен спонсор (имя, роль в организации)
- [ ] A02. Назначен менеджер проекта
- [ ] A03. Назначены ключевые члены команды
- [ ] A04. Резюме проекта заполнено (цель, выгоды, срок/стоимость, качество, границы, стейкхолдеры)
- [ ] A05. Карта результатов построена (дерево результатов с описаниями)
- [ ] A06. Риски определены, у каждого — мера реагирования и ответственный (Реестр последующих действий)
- [ ] A07. Ревью запуска: другой РП/эксперт проверил пакет запуска
- [ ] A08. Спонсор принял решение Go/No-go
- [ ] A09. Стартовая встреча с командой проведена
- [ ] A10. Фокусированная коммуникация отправлена тем, кого не было на встрече

## Планирование цикла (B — раз в 2–4 недели)

- [ ] B01. Планы обновлены и детализированы на цикл (по Карте результатов)
- [ ] B02. Ежемесячное ревью внешним ревьюером; оценка в Реестре «Здоровье проекта»
- [ ] B03. Go/No-go по циклу
- [ ] B04. Стартовая встреча цикла
- [ ] B05. Фокусированная коммуникация

## Еженедельно (C)

- [ ] C01. Прогресс оценён и зафиксирован (прогноз сроков/стоимости, коротко и наглядно)
- [ ] C02. Отклонения от плана — отреагированы
- [ ] C03. Еженедельная встреча
- [ ] C04. Фокусированная коммуникация

## Ежедневно (D)

- [ ] D01. Новые риски/проблемы/запросы на изменения — сразу в Реестр последующих действий
- [ ] D02. Выполненные результаты работы приняты

## Закрытие цикла (E — в конце каждого цикла)

- [ ] E01. Удовлетворённость стейкхолдеров оценена
- [ ] E02. Уроки извлечены, улучшения запланированы
- [ ] E03. Фокусированная коммуникация

## Закрытие проекта (F — один раз)

- [ ] F01. Продукт передан (и принимающая сторона подтвердила)
- [ ] F02. Удовлетворённость стейкхолдеров оценена
- [ ] F03. Ревью этапа закрытия
- [ ] F04. Проектная документация заархивирована
- [ ] F05. Окончание проекта отмечено (да, отпраздновать — это часть метода)
- [ ] F06. Фокусированная коммуникация

## После проекта (G — через несколько месяцев)

- [ ] G01. Выгоды оценены по сравнению с обещанными в Резюме проекта
- [ ] G02. Новые идеи сгенерированы
- [ ] G03. Фокусированная коммуникация
